# রিভার্স প্রক্সি (Reverse Proxy) — বাংলায় নোট

## ১. রিভার্স প্রক্সি কী?

রিভার্স প্রক্সি হলো এমন একটি সার্ভার, যা ক্লায়েন্টদের থেকে আসা অনুরোধ গ্রহণ করে এবং সেগুলোকে সঠিক ব্যাকএন্ড সার্ভারে পাঠায়।

এটি সাধারণত নিচের কাজ করে:

- ক্লায়েন্টের রিকোয়েস্ট গ্রহণ করে
- ডোমেইন, URL, অথবা লোড অনুযায়ী সেটিকে সঠিক সার্ভারে রুট করে
- সার্ভার থেকে আসা রেসপন্স আবার ক্লায়েন্টের কাছে ফেরত দেয়
- SSL, ক্যাশিং, নিরাপত্তা, authentication, rate limiting ইত্যাদি পরিচালনা করে

উদাহরণস্বরূপ:

- ব্যবহারকারী `example.com`-এ ঢুকলে
- Nginx বা Traefik রিকোয়েস্টটি Node.js API বা React app-এ পাঠিয়ে দেয়
- ব্যবহারকারী জানে না কোন সার্ভারে আসলে কাজ হচ্ছে

## ২. ফরোয়ার্ড প্রক্সি বনাম রিভার্স প্রক্সি

### ফরোয়ার্ড প্রক্সি

- ক্লায়েন্টের সামনে থাকে
- ব্যবহারকারী ইন্টারনেটের জন্য প্রক্সি ব্যবহার করে
- সাধারণত VPN, অফিসের নেটওয়ার্ক, ফিল্টারিংয়ের জন্য ব্যবহৃত হয়

### রিভার্স প্রক্সি

- সার্ভারের সামনে থাকে
- ব্যাকএন্ড সার্ভিসকে প্রকাশ্য পোর্ট থেকে রক্ষা করে
- অনেক অ্যাপ একসাথে একই public IP-এ চলতে সাহায্য করে

## ৩. রিভার্স প্রক্সির কারণ

রিভার্স প্রক্সি ব্যবহার করার অনেক কারণ আছে:

- একটি VPS বা সার্ভারে একাধিক অ্যাপ চালানো
- 80/443 পোর্টে একাধিক ডোমেইন পরিচালনা
- HTTPS/SSL পরিচালনা
- নিরাপত্তা বৃদ্ধি
- লোড কমানো
- static file cache করা
- API gateway হিসেবে কাজ করা

## ৪. রিভার্স প্রক্সির ব্যবহার

রিভার্স প্রক্সি সাধারণত এই কাজে ব্যবহৃত হয়:

- ওয়েবসাইট হোস্ট করা
- API routing
- microservice-এ request forward করা
- Docker কন্টেইনারের সামনে proxy হিসেবে কাজ করা
- TLS termination
- request logging ও monitoring

## ৫. জনপ্রিয় রিভার্স প্রক্সি টুলস

- Nginx
- Traefik
- Caddy
- Apache
- HAProxy

## ৬. Nginx উদাহরণ

```nginx
server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

এখানে:

- `listen 80;` → HTTP রিকোয়েস্ট শুনছে
- `server_name example.com;` → ডোমেইন নির্ধারণ করেছে
- `proxy_pass` → অনুরোধটাকে ব্যাকএন্ডে পাঠাচ্ছে

## ৭. রিভার্স প্রক্সির সুবিধা

- নিরাপত্তা বাড়ে
- backend server-কে private network-এ রাখতে পারে
- SSL এক জায়গায় নিয়ন্ত্রণ করা যায়
- request routing সহজ হয়
- static asset cache করার সুবিধা থাকে
- system complexity কমে

## ৮. কিছু সীমাবদ্ধতা

- কনফিগারেশন ভুল হলে রাউটিং সমস্যা হতে পারে
- debugging কিছুটা কঠিন হতে পারে
- ssl, cache, rate limit ইত্যাদি ঠিকমতো কনফিগার করতে হয়

## ৯. উপসংহার

রিভার্স প্রক্সি ওয়েব অ্যাপসের জন্য অত্যন্ত গুরুত্বপূর্ণ একটি উপাদান। এটি সার্ভারের নিরাপত্তা, স্কেলিং, রাউটিং, SSL, এবং পারফর্মেন্স উন্নত করতে সাহায্য করে। ডকার, VPS, ক্লাউড, এবং microservice-এ এটি খুব জনপ্রিয়।

এক কথায়, রিভার্স প্রক্সি হলো "বহু পরিষেবার সামনে থাকা সুরক্ষিত দরজার মতো"।
